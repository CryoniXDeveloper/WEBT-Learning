Tvorba tlačítek a navigace

Povaha elementů a její změna

Základní problém při stylování odkazů spočívá v jejich povaze. Tag <a> je od přírody řádkový (inline) element. To znamená, že na něj nefungují vlastnosti jako width, height ani vertikální padding/margin s fyzickým odtlačením okolí. Pokud chceme z obyčejného textového odkazu vytvořit masivní klikací tlačítko, musíme jeho povahu změnit.

Použijeme vlastnost display: block nebo display: inline-block. Tím odkaz získá vlastnosti obdélníkové krabičky a začne reagovat na rozměry a okraje.

Tvorba tlačítek v CSS

Tlačítko vytvoříme tak, že řádkovému odkazu zrušíme podtržení, přidáme vnitřní okraje, nastavíme výraznou barvu pozadí a změníme kurzor. Pro interaktivitu využíváme pseudotřídu :hover, která se aktivuje ve chvíli, kdy nad prvek najede myš.
.tlacitko {
  display: inline-block;
  text-decoration: none;
  background-color: #00b85c;
  color: white;
  padding: 10px 25px;
  border-radius: 6px;
  transition: all 0.3s ease;
}

.tlacitko:hover {
  background-color: #00d66b;
}

Svislá a vodorovná navigace

Základem každého navigačního menu na webu je prostý seznam <ul> obsahující položky <li> s odkazy. Proč seznam? Protože menu je logický "výčet odkazů". Pro vytvoření svislé navigace (sidebar) pouze odstraníme odrážky přes list-style-type: none a okraje z <ul>.

Pro vytvoření klasické vodorovné navigace v hlavičce navíc nastavíme na <ul> vlastnost display: flex, což okamžitě poskládá všechny položky seznamu vedle sebe do jednoho plynulého řádku.
<nav>
  <ul>
    <li><a href="index.html">Domů</a></li>
    <li><a href="lekce.html">Lekce</a></li>
    <li><a href="ukoly.html">Úkoly</a></li>
  </ul>
</nav>
nav ul {
  display: flex;
  gap: 20px;
  list-style-type: none;
}
