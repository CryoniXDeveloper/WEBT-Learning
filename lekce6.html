Obrázky

Vložení obrázku do HTML dokumentu

Obrázky dělají web vizuálně atraktivním. V HTML se obrázky nevkládají přímo do zdrojového kódu jako text, ale pouze na ně odkazujeme. K tomu se používá nepárový tag <img>. Tento tag sám o sobě nic nedělá, pokud mu pomocí atributu neřekneme, jaký soubor má z disku nebo internetu načíst. Zásadní je také atribut alt, který se zobrazí, pokud se obrázek nenačte, a čtou ho hlasové čtečky pro nevidomé.
<img src="pes.jpg" alt="Fotografie hnědého psa na louce">

Nastavení obrázku v HTML

Základní vlastnosti obrázku lze nastavit rovnou v tagu <img> pomocí atributů. Složitější úpravy vzhledu se ale dělají v CSS.
  • width, height Šířka a výška obrázku v pixelech, např. width="300". Pokud zadáte jen jeden rozměr, druhý se dopočítá podle poměru stran. Při zadání obou rozměrů je nutné dodržet poměr stran, jinak se obrázek zdeformuje.
  • alt Alternativní text, který se zobrazí při chybě načtení a čtou ho čtečky pro nevidomé.
  • title Popisek, který se zobrazí po najetí myší na obrázek.
<img src="pes.jpg" alt="Fotografie hnědého psa na louce" width="300" height="200" title="Můj pes">

Absolutní a relativní adresy

Při zadávání cesty k obrázku (atribut src) se musíme rozhodnout, odkud obrázek bereme.

Absolutní adresa

Odkazuje na přesné místo kdekoli na internetu. Vždy začíná protokolem http:// nebo https://. Příklad: src="https://domena.cz/obrazek.png". Výhodou je, že obrázek nemusíte mít u sebe, nevýhodou, že pokud ho cizí web smaže, zmizí i vám.

Relativní adresa

Odkazuje na soubor vzhledem k aktuálnímu HTML dokumentu. Příklad: src="obrazky/logo.png". Tento způsob se používá pro všechny obrázky, které tvoří design vašeho webu a nahráváte si je na server sami.

Nastavení a formátování v CSS

Obrázky mohou být v původním rozlišení obrovské a rozbít celý layout. Pomocí CSS je můžeme přizpůsobit našim potřebám, zaoblit jim rohy nebo je oříznout do kruhu.
img {
  max-width: 100%;
  height: auto;
  border-radius: 15px;
}
  • max-width: 100% Zajistí, že obrázek nikdy nepřeteče svého rodiče (např. mobilní displej), ale zmenší se podle něj.
  • border-radius Vytváří zaoblené rohy. Pokud použijete hodnotu 50% u čtvercového obrázku, vytvoří se dokonalý kruh (často používané pro profilové fotky).
