Rozměry, okraje, rámečky

Blokový model CSS (Box Model)

Základním stavebním kamenem celého webdesignu je pochopení takzvaného blokového modelu. Webový prohlížeč vnímá naprosto každý HTML element (odstavec, nadpis, obrázek, odkaz) jako neviditelnou obdélníkovou krabičku (box). Z těchto krabiček se pak skládá celá stránka. Velikost samotného obsahu uvnitř krabičky určujeme pomocí vlastností width (šířka) a height (výška).

Obsah (Content)

Samotné jádro krabičky. Je to prostor, kde se fyzicky nachází text, obrázek nebo video. Právě na tuto část se aplikují rozměry width a height.

Rámeček (Border)

Linka, která celou krabičku obaluje. Může být neviditelná, plná, čárkovaná nebo tečkovaná. Odděluje vnitřní prostor elementu od vnějšího okolí.

Okraje (Padding / Margin)

Neviditelné deformační zóny kolem obsahu. Určují, jak daleko bude text od rámečku a jak daleko bude celá krabička od ostatních krabiček na webu.

Vnitřní a vnější okraje (Padding vs Margin)

Rozdíl mezi těmito dvěma vlastnostmi je pro začátečníky často matoucí, ale je naprosto klíčový. Padding (vnitřní okraj) představuje vycpávku uvnitř krabičky. Odtlačuje obsah (text) směrem dovnitř od rámečku. Pokud má element nastavenou barvu pozadí, padding bude mít tuto barvu také.

Naopak Margin (vnější okraj) je prostor ZVENKU rámečku. Funguje jako ochranná bublina, která odtlačuje sousední elementy pryč. Margin je vždy 100% průhledný a nelze mu nastavit barvu.
.informacni-karta {
  width: 300px;
  background-color: #2163be;
  padding: 20px;
  margin: 15px;
  border: 2px solid white;
}
  • border Sdružená vlastnost, která definuje tloušťku (2px), styl (solid - plná čára) a barvu (white). Styl může být také dashed (čárkovaný) nebo dotted (tečkovaný).
  • Zápis okrajů Když zadáme padding: 20px, aplikuje se okraj ze všech 4 stran. Lze ale určit i konkrétní stranu: margin-top, margin-bottom, margin-left, margin-right.
