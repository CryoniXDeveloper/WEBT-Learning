Seznamy

Neuspořádaný a uspořádaný seznam

HTML zná dva hlavní druhy seznamů. Oba se skládají z obalovacího tagu, který určuje typ seznamu, a vnitřních tagů, které definují samotné položky. Odrážka nebo číslo se k položce přidá automaticky.

Neuspořádaný seznam (UL)

Unordered List. Tvoří se tagem <ul>. Používá se pro výčty, kde nezáleží na pořadí (nákupní seznam). Výchozím znakem je černý puntík.

Uspořádaný seznam (OL)

Ordered List. Tvoří se tagem <ol>. Používá se tam, kde je nutná posloupnost (např. recept, postup instalace). Výchozím znakem je číslo.
<ul>
  <li>První položka seznamu</li>
  <li>Druhá položka seznamu</li>
</ul>

Formátování seznamů v CSS

Pomocí CSS vlastnosti list-style-type můžeme zcela změnit chování odrážek. U neuspořádaných můžeme mít čtverečky (square) nebo prázdná kolečka (circle). U uspořádaných lze nastavit římské číslice (upper-roman) nebo písmena (lower-alpha). Nejčastější použití je ale hodnota none, která odrážky zcela odstraní – to se používá při tvorbě navigačních menu.
ul {
  list-style-type: none;
  padding: 0;
  margin: 0;
}
