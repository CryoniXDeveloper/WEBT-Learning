Tabulky

Struktura tabulky v HTML

Tabulky v HTML mohou působit zpočátku složitě, protože se neskládají z jednoho tagu, ale z hnízdění několika tagů do sebe. Historicky se tabulky používaly na tvorbu celého rozvržení webu, dnes se striktně používají pouze pro zobrazení tabulkových dat (ceníky, kalendáře).
  • <table> Hlavní kontejner, který obaluje celou tabulku.
  • <tr> Table Row. Vytváří jeden vodorovný řádek tabulky. Všechny buňky musí být zanořeny uvnitř něj.
  • <th> Table Header. Buňka hlavičky. Slouží k popisu sloupce (např. "Cena"). Text je ve výchozím stavu tučný a vycentrovaný.
  • <td> Table Data. Běžná buňka obsahující samotná data.
<table>
  <tr>
    <th>Položka</th>
    <th>Cena</th>
  </tr>
  <tr>
    <td>Kniha</td>
    <td>250 Kč</td>
  </tr>
</table>

Slučování buněk

Pokud chceme, aby se buňka roztáhla přes více polí (stejně jako funkce Merge v Excelu), používáme atributy přímo v HTML tagu <td>. Atribut colspan="2" sloučí buňku přes dva sloupce vodorovně. Atribut rowspan="3" roztáhne buňku přes tři řádky dolů. Zbylé buňky, přes které se sloučení provedlo, se z kódu musí smazat.
<table>
  <tr>
    <th>Položka</th>
    <th>Cena</th>
  </tr>
  <tr>
    <td colspan="2">Doprava zdarma</td>
  </tr>
</table>

Formátování tabulky v CSS

Ve výchozím stavu HTML nevykresluje tabulkám žádné okraje a buňky jsou na sebe natlačené. Pomocí CSS nastavujeme tabulce šířku, vnitřní odsazení buněk (padding) a rámečky. Klíčová je vlastnost border-collapse: collapse;, která zruší zdvojené čáry mezi buňkami.
table {
  width: 100%;
  border-collapse: collapse;
}

th, td {
  border: 1px solid white;
  padding: 15px;
  text-align: left;
}
