Kaskádové styly a jejich syntaxe

Význam, struktura a syntaxe CSS

HTML samotné je velmi ošklivé – černý text na bílém pozadí bez jakéhokoliv rozvržení. Zde přichází na scénu CSS (Cascading Style Sheets). Je to jazyk, který prohlížeči říká, JAK se mají HTML prvky vykreslit. Díky CSS můžeme měnit barvy, velikosti písma, tvořit složité layouty (rozvržení), animace a přizpůsobovat web pro mobilní telefony.

Zápis (pravidlo) v CSS se skládá ze dvou hlavních částí: Selektoru (kdo se má změnit) a Deklaračního bloku ve složených závorkách (jak se má změnit). Každá deklarace uvnitř bloku končí středníkem!
/* Struktura CSS pravidla */
selektor {
  vlastnost: hodnota;
  dalsi-vlastnost: hodnota;
}

/* Reálná ukázka: Obarvení všech nadpisů h1 na modro */
h1 {
  color: blue;
  font-size: 24px;
}

Propojení CSS a HTML

Aby prohlížeč věděl, jaké styly má na HTML dokument aplikovat, musíme tyto dva soubory propojit. Nejlepší, nejprofesionálnější a nejpoužívanější způsob je vytvořit samostatný soubor (např. style.css) a na ten v HTML dokumentu odkázat. Tento odkaz se umísťuje do hlavičky <head> pomocí nepárového tagu <link>. Díky tomu můžeme mít jeden CSS soubor, který řídí vzhled třeba tisíce HTML stránek najednou (celého e-shopu).
<head>
  <title>Můj Web</title>
  <!-- Atribut rel říká, že jde o stylopis (stylesheet), href ukazuje cestu -->
  <link rel="stylesheet" href="style.css">
</head>

Selektory, třídy a identifikátory

Selektory jsou nesmírně důležité. Určují, na jaké HTML tagy se má daný CSS kód aplikovat. Pokud použijeme pouhý název tagu (např. p), aplikuje se styl na VŠECHNY odstavce na webu. Co když ale chceme mít jeden odstavec červený jako varování a zbytek normální? K tomu slouží Třídy (Classes) a Identifikátory (ID).

Selektor Tagu

Zápis bez tečky nebo křížku, např. button { color: red; }. Vybere a upraví absolutně všechna tlačítka v dokumentu. Používá se pro globální nastavení výchozího vzhledu webu.

Třída (.class)

Zapisuje se s tečkou, např. .varovani { color: red; }. V HTML pak napíšeme <p class="varovani">. Třídu můžeme na jedné stránce použít kolikrát chceme na různé prvky.

Identifikátor (#id)

Zapisuje se s křížkem, např. #hlavni-nadpis { color: blue; }. V HTML pak <h1 id="hlavni-nadpis">. ID musí být unikátní! Lze jej na stránce použít pouze a jenom jednou.
