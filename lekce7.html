Odkazy

Hypertextový a jmenný odkaz

Odkazy dělají z obyčejného textu síť (World Wide Web). K jejich vytvoření slouží párový tag <a>. To, kam má odkaz směřovat, určuje atribut href. Odkaz může vést i na e-mailovou adresu: <a href="mailto:jmeno@domena.cz">.

Klasický odkaz

Směřuje na jinou stránku. Příklad: <a href="stranka.html">Klikni sem</a>. Pokud chceme, aby se otevřel v novém okně, přidáme atribut target="_blank".

Jmenný odkaz (Kotva)

Nasměruje uživatele na konkrétní místo na téže stránce. Prvku, kam chceme skočit, přiřadíme ID (např. id="sekce3") a odkaz vytvoříme jako <a href="#sekce3">.

Obrázek jako odkaz

Odkazem nemusí být pouze text. Jakýkoliv prvek, který vložíme mezi tagy <a> a </a>, se stane klikacím. Nejčastěji se takto tvoří klikací loga nebo galerie.
<a href="index.html">
  <img src="logo.png" alt="Logo webu">
</a>

Formátování odkazů v CSS

Ve výchozím stavu prohlížeče vykreslují odkazy modře a s podtržením, a pokud je navštívíte, zfialoví. Pro moderní design toto musíme přepsat. Pomocí pseudotříd můžeme dokonce nastavit, jak má odkaz vypadat, když na něj najedeme myší.
a {
  text-decoration: none;
  color: #2163be;
}

a:hover {
  color: #ff5100;
}
