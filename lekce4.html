Text a jeho formátování, pozadí stránky

Pozadí stránky v CSS

Jednou z prvních věcí, které při tvorbě designu webu nastavujeme, je pozadí. Tradičně se pozadí nastavuje přímo na tag <body>, čímž se zbarví celá viditelná plocha prohlížeče. K dispozici máme buď plné barvy, barevné přechody (gradienty), nebo obrázky.
  • background-color Definuje plnou barvu pozadí. Barvu můžeme zapsat anglickým slovem (red, blue), hexadecimálním kódem (např. #ff0000) nebo pomocí rgb() a rgba() pro průhlednost.
  • background-image Umožňuje nastavit obrázek na pozadí pomocí funkce url('cesta/k/obrazku.jpg'). Pokud je obrázek menší než obrazovka, automaticky se začne opakovat jako dlaždice.
  • background-size Řeší problém s velikostí obrázku na pozadí. Hodnota cover zajistí, že obrázek pokryje celou plochu (případně se ořízne), hodnota contain zajistí, že bude vidět celý, i za cenu prázdných pruhů po stranách.

Nadpisy, odstavce a formátování textu v CSS

Web je z 90 % tvořen textem. Typografie (práce s písmem) je pro úspěšný web naprosto klíčová. Návštěvník musí být schopen text snadno číst, proto nastavujeme dostatečný kontrast, velikost a mezery.

Základní vlastnosti písma

color: mění barvu samotného textu.
font-size: velikost písma (nejčastěji v pixelech - px, nebo v relativních jednotkách rem). Výchozí velikost odstavce v prohlížečích je 16px.
font-family: druh písma (Arial, Roboto, Times New Roman).

Stylování odstavců

font-weight: tloušťka písma (bold pro tučné, normal pro normální).
text-align: zarovnání textu (left, right, center, justify - do bloku).
line-height: výška řádku. Pro dobrou čitelnost textu se doporučuje hodnota 1.5 nebo 1.6 (mezera mezi řádky).
/* Kompletní úprava vzhledu článku */
body {
  background-color: #f4f4f4;
  font-family: Arial, Helvetica, sans-serif;
}

h1 {
  color: #333333;
  text-align: center;
  font-size: 36px;
}

p {
  color: #555555;
  line-height: 1.6;
  font-size: 18px;
}
